# M.A.R.K. meta site

Astro landing page for the M.A.R.K. lineage. This repository is intentionally a small meta
repository: it points to the individual Marks and does not duplicate their source code.

## Run locally

```bash
npm ci
npm run dev
npm run check
npm run build
```

The project-page base URL is configured in `astro.config.mjs`.

## Scope

- M.A.R.K. I → [Assistant-mark-I](https://github.com/Brightwav3/Assistant-mark-I)
- M.A.R.K. II → [Assistant-mark-II](https://github.com/Brightwav3/Assistant-mark-II)
- M.A.R.K. III → future conversational boundary; no repository published yet
